Demonstração do Sistema de Autenticação

Este é o novo fluxo de autenticação da Last Dance Club. O sistema detecta automaticamente o tipo de usuário baseado no domínio do e-mail e redireciona para o dashboard apropriado.

Tipos de Usuário

Cliente

Domínios: @gmail.com, @outlook.com, @hotmail.com, @yahoo.com, etc.

Exemplos:

  • joao@gmail.com
  • maria@outlook.com
  • pedro@yahoo.com.br
Redireciona para: cliente-dashboard.html
Ir para dashboard

Vendedor

Domínios: Qualquer e-mail com "@vendedor"

Exemplos:

  • loja@vendedor.com
  • contato@vendedor.com.br
  • maria@vendedor.net
Redireciona para: vendedor-dashboard.html
Ir para dashboard

Admin

Domínios: Qualquer e-mail com "@admin"

Exemplos:

  • admin@admin.com
  • suporte@admin.com.br
  • gerente@admin.net
Redireciona para: admin-dashboard.html
Ir para dashboard

Código JavaScript

Função que detecta o tipo de usuário:

function tipoDeUsuarioPeloEmail(email) { var e = email.toLowerCase(); if (e.indexOf('@admin') !== -1) { return 'admin'; } else if (e.indexOf('@vendedor') !== -1) { return 'vendedor'; } else { return 'cliente'; // Gmail, Outlook, etc. } }
